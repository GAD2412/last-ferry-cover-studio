Last Ferry turns local pictures into illustrated coastal crime posters. Open the sample, drop your own photos into the panels, edit the title, and download a square, portrait, or landscape PNG.

## Run it

Open `app/index.html` in desktop Chrome. On macOS you can launch it from the repository with

```sh
open -a "Google Chrome" app/index.html
```
